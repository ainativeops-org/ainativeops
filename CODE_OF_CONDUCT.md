# Code of Conduct

AiNativeOps adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions and any event where a participant represents the project.

Report a violation privately to the maintainers (see [GOVERNANCE.md](GOVERNANCE.md)); until they are named, write to the owners of the `ainativeops` GitHub organisation. Maintainers review every report, keep the reporter's identity confidential and decide on the measures listed in the Covenant.

---

# Правила поведения

AiNativeOps принимает [Contributor Covenant версии 2.1](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/). Правила действуют в issue, pull request, обсуждениях и на любом мероприятии, где участник представляет проект.

О нарушении сообщите лично мейнтейнерам (см. [GOVERNANCE.md](GOVERNANCE.md)). Пока они не названы, пишите владельцам организации `ainativeops` на GitHub. Мейнтейнеры рассматривают каждое сообщение, не раскрывают имя заявителя и принимают меры, предусмотренные Covenant.
