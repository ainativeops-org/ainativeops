# AiNativeOps alpha 0.2

**Карта:** https://ainativeops.org · **alpha 0.1:** https://ainativeops.org/0.1/ · [English below](#english)

Alpha 0.2 превращает карту из каталога классов в карту процессов. Двадцать процессов проходят маршрутом по трём видам: «Архитектура», «Инфраструктура» и «Стек». У каждого процесса есть блок-схема с развилками, отказами и исходами, а у каждого элемента карты — источники.

## Что нового

- **Процессы.** 20 процессов в 10 группах и 38 маршрутов. Процесс с вызовом модели получил два маршрута: модель в своём контуре и внешний API. Маршрут проходит каждый компонент один раз. Участники шага и его опоры показываются на карте, пока этот шаг выбран.
- **Защищённый вызов модели.** Каждый маршрут с вызовом модели проходит входные и выходные защитные проверки, проверку квоты и журнал аудита, валидатор это проверяет.
  - `RM-MOD-12` «Классификатор запросов» выбирает профиль маршрута среди моделей, которые разрешает политика раскрытия.
  - `RM-MOD-13` «Планировщик вызовов моделей» разбивает составной запрос на подзадачи для самых дешёвых достаточных моделей.
- **Учёт потребления.** `RM-OPS-06` теперь называется «Учёт потребления и биллинг ИИ». В него попадает каждое обращение агента или модели: вызов модели, допущенное действие, задание в изолированной среде, запрос к знаниям.
- **AI Safety Core.** Группы называются «Безопасность исполнения · PDP / PEP», «Безопасность инференса · Guardrails» и «Безопасность данных». Новый класс `RM-AIC-05` «Квоты и защита от злоупотреблений».
- **Источники.** В реестре 91 источник трёх типов: стандарты, опубликованные практики, примеры реализации. К источникам привязан каждый элемент трёх видов и каждая зона.
- **Карта.** Маршрут процесса стал первым слоем карты, его линии идут по промежуткам между зонами и не пересекают блоки. В панелях нет капса и плашек. Карточка процесса показывает блок-схему рядом с описанием выбранного шага. Переключатель версий ведёт на alpha 0.1.

## Совместимость

Это alpha-версия: состав классов, их названия и ключи RM могут измениться в любом выпуске до 1.0. Изменения против 0.1 перечислены в [CHANGELOG.md](../../CHANGELOG.md). Документы соответствия и договоры на ключах alpha-версии строить не стоит.

## Известные ограничения

- Ни один маршрут пока не использует классы Confidential Computing, `RM-DPR-05` «Шифрование данных» и `RM-DPR-07` «Контроль доступа к памяти агента».
- Ссылки на источники мейнтейнеры ещё не проверяли, а у 62 источников не указан раздел.

Замечания и предложения принимаются через форму «Предложить правку» в карточке любого элемента карты.

# AiNativeOps alpha 0.2

**Map:** https://ainativeops.org · **alpha 0.1:** https://ainativeops.org/0.1/

Alpha 0.2 turns the map from a catalogue of classes into a map of processes. Twenty processes trace a route through the three views: Architecture, Infrastructure and Stack. Every process has a workflow with decisions, failure exits and outcomes, and every element of the map has sources.

## What is new

- **Processes.** 20 processes in 10 groups and 38 routes. A process that calls a model has two routes: the model inside the boundary and an external API. A route visits each component once. The participants and dependencies of a step appear on the map while that step is selected.
- **Guarded model call.** Every route that calls a model passes input and output guardrails, the quota check and the audit log; the validator enforces it.
  - `RM-MOD-12` Request classifier picks a route profile among the models that the disclosure policy permits.
  - `RM-MOD-13` Model call planner splits a composite request into subtasks for the cheapest sufficient models.
- **Usage metering.** `RM-OPS-06` is now AI usage metering and billing. Every touch of an agent or a model reaches it: a model call, an admitted action, a job in the isolated environment, a knowledge query.
- **AI Safety Core.** The groups are Execution protection · PDP / PEP, Inference protection · Guardrails and Data protection. New class `RM-AIC-05` Quotas and abuse protection.
- **Sources.** A registry of 91 sources of three types: standards, published practices, implementation examples. Every element of the three views and every zone is bound to sources.
- **Map.** The process route is the first layer of the map; its lines run along the gaps between zones and cross no block. Panels have no uppercase labels or chips. The process card shows the workflow beside the selected step. The version switcher leads to alpha 0.1.

## Compatibility

This is an alpha: the set of classes, their names and RM keys may change in any release before 1.0. Changes since 0.1 are listed in [CHANGELOG.md](../../CHANGELOG.md). Do not build compliance documents or contracts on RM keys of an alpha version.

## Known limitations

- No route uses the Confidential computing classes, data encryption `RM-DPR-05` or agent memory access control `RM-DPR-07` yet.
- No source link is verified by a maintainer yet, and 62 sources have no section.

Comments and proposals are welcome through the "Propose a change" form in the card of any element on the map.
